# Telegram-bot EnglishVinglish
Данный телеграм бот предназначен для запоминания английских слов, но при желании можно и использовать любой другой язык. В данной реализации изначально предлагается на обучение 10 начальных слов, словарный запас можете увеличивать самостоятельно, через кнопку Добавить слово.
 Бот рандомно выбирает слово и предлагает вам выбрать перевод из четырех вариантов.
